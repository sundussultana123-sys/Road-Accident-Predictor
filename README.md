# Road Accident Predictor 🚗

An ML-powered web application that predicts road accident severity based on environmental and situational factors.

## Features
- Predict accident severity (Minor/Moderate/Severe)
- Interactive input controls
- Real-time probability visualization
- Risk factor identification
